# Documentation Governance

This section controls authority, lifecycle, traceability, and release readiness.

Read in this order:

1. `source-of-truth.md`: precedence and conflict resolution.
2. `documentation-policy.md`: required metadata and update rules.
3. `release-levels.md`: maturity claims from development through production.
4. `definition-of-done.md`: task, phase, and release completion.
5. `definition-of-production-ready.md`: non-negotiable L3 release gates.
6. `specification-reconciliation.md`: how promoted detailed specs interact with newer production authorities.
